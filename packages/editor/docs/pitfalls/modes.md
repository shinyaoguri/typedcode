# packages/editor — 罠: 入口とモード (練習・試験・授業 / 課題・問題パネル)

パスからのモードの判定、試験の開始ゲートと解錠、`.tcexam` / `.tcclass`、問題パネルを触るときに読む。[AGENTS.md](../../AGENTS.md)「よくある罠」に見出しがあり、ここが本文 (理由・経緯・回帰テスト)。罠を足すときは、ここに本文を書き、AGENTS.md には見出しを 1 行足す。

`core/`・`services/`・`ui/` などで始まるコードのパスは `packages/editor/src/` から見たもの。

- **問題の入出力例は表示するだけで、判定も記録もしない (#648 / ADR-0048)**: 問題パネルは `ProblemPanel.setProblem(statement, examples?)` で問題文と例の節を 1 回で描き直す (タブ切替で前の問題の例を残さないため)。描く経路は `main.ts` の `openBundleTabs` / `openClassTabs` / `restoreExamProblemDisplay` / `restoreClassProblemDisplay` と `TabChangeHandler` の 5 か所で、例は `ExamPackageStore` / `ClassProblemStore` の保存形 (`examples?`) から引く。**問題を描く経路を足すときは examples も渡す** (渡し忘れるとリロードやタブ切替の後だけ例が消える)。例の中身は textContent で入れる (配布物の文字列を HTML にしない)。コピーは `SessionContentRegistry` に登録しない (登録すると `copyOperation` が proof に載る) ので、コピーした入力をコードエディタに貼ると外部の貼り付けになる。ターミナルの `terminalInput` の行の区切りは `terminal/stdinLineDiscipline.ts` (Python の stdin と共有) で 1 文字ずつ行うので、貼り付けの塊も行ごとに記録される (Ctrl+C で書きかけの行を捨てるのは `CTerminal` 側)。`/author` が配る例は教材フォルダのケースファイルの `public: true` から作る。ケースの `name` が空のファイルは定義として読めず (`authoring/workspace/definitions.ts`)、書き出しが止まる。生成器 (`createExamBundlePackage` / `buildClassPackage`) も名前の空の例を落とす (`authoring/problemExamples.ts`。shared の `parseExamBundle` は空の名前を拒否するので、空の名前の例を配布物に入れない)
- **入口は学生にモードを選ばせない (ADR-0046、#644。ADR-0015 のランディングを置き換え)**: `resolveRoute()` は `/` と `/casual` を `'casual'` (練習のエディタを直接開く)、`/class` `/assignment` `/exam` を各モード、作業スペース `/w/class/<classId>/<方針>` を方針から決まるモード (#646)、**それ以外と形の崩れた `/w/...` を `'not-found'`** にする (タイポ `/exsm` を黙って練習にしない = ADR-0015 から引き継ぐ事故防止)。**エントリは `entry.ts`** (`index.html` が読む) で、not-found なら `NotFoundPage` (`/` へのリンクだけ) を描き、それ以外でだけ `main.ts` を dynamic import する (#302)。**`entry.ts` とそこから静的に届くモジュール (`NotFoundPage`・`i18n`・`core/mode.ts`・`core/stateContract.ts`・`app/bootFailure.ts`) から `main.ts` やエディタ側のモジュールを静的 import しない** (not-found の初期ロードに Monaco・実行系・xterm・Wasmer が乗る。`production-build.spec.ts` が見張る)。not-found でもエディタシェルの DOM (`index.html` の `#app`) は残るので、`NotFoundPage` が `display:none` にして外す。**titlebar はモード表示だけ** (`ModeBadge`)。別モードへ移る UI は持たない — モードは教員が配るリンクと配布物が決める (段階 2 = #645 で授業と課題を `.tcclass` の方針に統合、段階 3 = #646 で保存領域を配布物単位に = 下の「作業スペース」)。**練習 (casual=「練習/Demo」) の摩擦低減**: 利用規約モーダルを出さない (`ctx.mode!=='casual' && !hasAcceptedTerms()` のときだけ表示)。未同意なら `ready` の後に受動的な規約通知 (`TermsNotice`) を出し、閉じたら同意フラグを書いて全タブに `termsAccepted` を記録する (それより前に export した proof には載らない)。画面共有は能力 `promptScreenShareAtStart=false` で**起動時に勧誘せず opt-out 状態で開始** + 「画面共有を有効にする」バナー (既存 `onResume`) からオプトイン。**Turnstile `#0` は維持**。casual の**内部 id・storage (`ns=''`)・proof `mode` は不変**。
- **試験モードはパスで入る (ADR-0011, ADR-0010 の sticky を置換)**: `/exam` で試験モード (`ctx.mode==='exam'`、派生 `ctx.examMode`)。**モードは `resolveModeFromPath` で URL パスから毎回確定**するので sticky フラグを持たない (旧 `?exam=1` + `localStorage['typedcode-exam-mode']` を置換)。リロードでもパスが残り試験モードを維持。別パス (`/`) へ移れば抜けられるが、整合性は封印の暗号束縛 (ADR-0006) が担保するので閉じ込め不要 (抜けても有効な試験 proof は作れない)。**ストレージはモード別に名前空間化** (`core/storageKeys.ts`: session IndexedDB 名・sessionStorage キー (`tabs`/`session-active`)・問題キャッシュを `-<mode>` 化、**casual は従来名**で移行不要)。`main.ts` 最初期に `setStorageNamespace(mode)` (作業スペースなら `setWorkspaceStorageNamespace(workspace)`。#646) を 1 回呼び、各所はキー literal でなく storageKeys の getter を使う。これでモード間でセッションが**共存**し混ざらない (PR1/PR2 の auto-clear を置換。スクショは session DB の `screenshots` ストアなので自動で名前空間化される)。`ctx.examMode` が真の間は問題タブを 1 つ生成し、`TabManager.setExamLock(true)` で `createTab`/`closeTab` を源流ロック (add-tab/close ボタンは CSS で非表示)。提出は **Moodle で行うため TypedCode 側に「提出」操作は持たない**。ダウンロードは**問題パネルの「ログをダウンロード」ボタンに一本化** (`#download-log-btn` → `proofExporter.exportAllTabsAsZip()`、証明 + コードの ZIP) し、受験者がそれを Moodle に提出する。一本化のため**左のダウンロードボタン `#download-btn` (メニューを持たず、押すと全タブの ZIP を書き出す。#779) は exam モードで CSS 非表示**。問題パネルは右端ドラッグでリサイズ・× で閉じる・**左 Activity Bar** の `#toggle-problem-btn` で再表示 (VSCode 風。トグルは exam モードのみ表示)。**`?reset` は無い (ADR-0011 どおり撤去。#323)**: URL を開くだけで保存データが消える経路を持たない (`/exam?reset=1` のようなリンクで全モードの記録が消える事故の元だった)。消去は設定メニューの「このモードをリセット」(en は Reset This Mode) を確認ダイアログで確定したときだけで、**現在のモード (作業スペースならその作業スペース) の session DB とモード別キー (`storageKeys.ts` の `modeLocalStorageKeys` / `modeSessionStorageKeys`) だけ**を消す (ほかのモード・作業スペースのデータ、規約同意・表示言語・テーマ・Cookie は残す)。順序は `confirmReset` (`app/resetDialog.ts`): `skipBeforeUnload` を立て `TabManager.suspendPersistence()` で sessionStorage への保存を止める → `SessionStorageService.close()` で自分の接続を閉じる → `deleteDatabase` の `onsuccess` を待つ (close は走行中のトランザクションが終わるまで close pending なので `onblocked` が一時的に来る。`DELETE_BLOCKED_GRACE_MS` まで待ち、過ぎたら失敗。リロードせず通知。#524) → モード別キーを消す → パラメータ無しの URL へ遷移 (`utils/StorageClearHelper.ts`)。**新しいモード別の storage キーを足すときは `modeLocalStorageKeys` / `modeSessionStorageKeys` にも入れる**proof には生成時の `mode` を記録 (自己申告ラベル、ADR-0011)。モード体系 (casual/class/assignment/exam) と能力は `core/mode.ts`
- **試験モードの暗号コア解錠 (ADR-0006)**: 初回入場は `ExamStartGate` (全画面ブロック) で `.tcexam` 取込 + 監督コード → shared の `verifyExamPackageSignature`/`decryptExamPackage` → `TabManager.createTab({examContext})` が `TypingProof.initializeExam` で **genesis = 監督コード入力時にチェーン根を束縛** (`#0 humanAttestation` は best-effort、`#1 examOpened`)。**#0 の Turnstile はゲートの表示中に先行取得する (#236)**: `runExamUnlock` が `gate.prompt()` と並行に `TabManager.startExamPreAttestation` を走らせ、widget はゲート内の容器 (`ExamStartGate.attestationSlot()`) に描く (認証モーダルの z-index はゲートより下なので使わない)。対話チャレンジもゲートの中で解かせる。解錠の瞬間に `takeResult()` で決着済みの結果を取り、`createTab({ examContext, examVerification })` が純関数 `buildExamHumanAttestation` (`ui/tabs/humanAttestation.ts`) で #0 を作る: token があれば verified (`session-start-token:<keyId>`)、未決着 (`null`) なら**待たずに** (猶予 0 秒 = ADR-0006 のサーバを critical path に置かない) 合成の印 (`verified:false` / `signature:'unsigned'`)、失敗で決着していれば合成に `failureReason` を添える。未決着の取得は表示中のチャレンジを止め (token を得た後の session/start は止めない)、遅れて届いた token は署名専用にだけ使う (#0 にも root にも焼かない)。バンドルの 2 番目以降は従来どおり先頭の #0 を共有する。問題本文は `ProblemPanel` 表示 + `ExamPackageStore` (localStorage) に保存しリロードで再表示。`examContext` は IndexedDB/sessionStorage の proof 状態 3 経路に透過。**export 前 Turnstile も exam では best-effort** (`ProofExporter.setPreExportBestEffort(true)` を `capabilities.preExportBestEffort` で駆動、Workers 不達でも ZIP を出す)。dev 出題者鍵は `shared/.../examAuthorityKeys/localKeys.ts` (gitignore 済み。#338)
- **試験の許可言語は境界ごとに判定する (#727)**: 判定は shared の `examAllowedLanguages` / `isExamLanguageAllowed` (grader の `proof.language` 照合と同じ実装) で、タブへの当てはめは `app/examLanguageGuard.ts` (`languagePolicyFor`)。呼ぶ境界は言語セレクタの選択肢 (`syncLanguageSelector`、タブ切替・復元で呼ぶ)・言語変更 (`TabManager.setLanguageGuard`。拒否なら変えずに false)・実行開始 (`CodeExecutionController.setLanguageGate`)・HTML プレビュー (`BrowserPreviewPanel` の `isTabLanguageAllowed`)。**選択肢を隠すだけにしない** (select の値の直接書き換えや保存状態の復元で非許可の言語になったタブを止められない)。exam のタブは `ExamPackageStore` の manifest (+ v2 の `starterLanguage`) を引くので、開封時はタブを作る**前に**ストアへ保存する。パッケージが引けない exam タブは何も許可しない (fail-closed)。casual / class / assignment は制限しない。復元したタブの言語は書き換えない (実行・プレビューを止め、提出物は verifier が照合する)。新しく「言語で動く入口」を足すときもこの判定を通す
- **授業/課題モードの平文問題配布 (ADR-0014/0015)**: `/class`・`/assignment` は**封印しない** (問題は公開、tier ① 自己申告)。**問題は左 Activity Bar の「問題を読み込む」(`#load-problem-btn` → `runClassLoad`) でいつでも取り込める** — 起動時に強制ローダは出さない (ADR-0015)。読み込むとその配布物の作業スペースへ移り、移り先の起動がタブを開く (#646。下の「作業スペース」)。`ClassProblemLoader` (**非ブロッキング**・監督コードなし・スキップ可) で平文 `.tcclass` (`{schema:'tcclass/1', classId, allowed, bundle}`、shared の `parseClassPackage` で**構造検証のみ・署名検証なし**) を取込 → (作業スペースで) `openClassTabs` が各問を **casual タブ** (`examContext` なし = **root 束縛なし**) で N タブ展開。starter は既存の `recordTemplateInjection` で注入し `templateName='tcclass/${classId}/${problemId}'` が **self-asserted problemId** を proof に残す (新イベント型/proof フィールドを足さない = `PROOF_FORMAT_VERSION` 据え置き・完全後方互換)。問題本文は `ProblemPanel` + `ClassProblemStore` (**filename キー**。class タブは examContext を持たず problemId を proof から引けないため、タブ切替/リロードの照合は filename で行う)。**問題パネルは問題が読み込まれるまで開かない** (ADR-0015。未読込なのに exam の「試験モード」見た目で出る不具合を解消) — `main.ts` の panel 初期化は `setTitle(t('feature.<mode>'))`(試験/授業/課題)だけ行い `show()` しない。表示は load/restore パスが行う。能力は `capabilities.problemPanel` (exam/class/assignment=true) で問題パネルを、`!sealedProblem` で「問題を読み込む」可否を判別する (`body.can-load-problem`。練習も出す = #646)。`body.has-problem-panel` がトグルボタン表示を制御 (`body.exam-mode` は exam 固有クロムだけに残す)。`/author` は同じ問題から `buildClassPackage` で未封印 `.tcclass` も出せる (examId を classId に流用)。**Turnstile storm 回避**は exam と同じ `sharedAttestation` (先頭タブ #0 を共有)
- **`.tcclass` の方針 (`policy`) は入口の能力より優先する (#645)**: 任意の `policy` (`screenshots` / `fullscreenTracking` / `preExportBestEffort`。3 つとも boolean 必須で、部分指定・型違いは shared の `parseClassPackage` がファイルごと拒否する) を、`core/mode.ts` の `capabilitiesWithPolicy` が入口の能力に重ねる。方針の無い配布物は入口の既定の方針で開く (`entranceClassPolicy`: 練習と `/assignment` は持ち帰り、`/class` は教室で実施、作業スペースの中はその作業スペースの方針)。**能力は起動時に決まり、ページの中では切り替えない** (#646): 方針の違う配布物は別の作業スペースになり、ページごと移る。#645 の `applyClassPolicy` (動いているページで tracker を止める・画面共有の選択を出す) は #646 で取り除いた。方針は `ClassPolicyStore` (名前空間別の localStorage) に覚え、作業スペースの起動はそれ (無ければ URL の方針) を重ねる。旧来の `/class` `/assignment` も、前に読み込んだ方針が残っていればそれで起動する (#645 の間に書いた値)。/author のプリセットは `CLASS_POLICY_PRESETS` (教室 = `/class`、持ち帰り = `/assignment` の能力から導出)。**作業スペースの `proof.mode` は方針から決まる** (`modeForClassPolicy`: 教室で実施 = `class`、持ち帰り = `assignment`、プリセットに無い組み合わせはスクリーンショットを撮るなら `class`、撮らないなら `assignment`。検証は `mode` を信頼に使わない = ADR-0020)
- **作業スペースは配布物ごとで、移るときは移り先の領域に書いてからページごと移る (#646 / ADR-0058)**: `.tcclass` を読み込むと `runClassLoad` が `classWorkspaceFor` (方針は配布物の方針、無ければ入口の既定) で作業スペースを決める。URL は `/w/class/<encodeURIComponent(classId)>/<方針の符号>` (`classroom` / `take-home` / `custom-<s><f><b>`)、名前空間は `-w:class:<…>:<…>` (`workspaceName`。種別を先頭に置き、試験の `exam:<examId>[:<variant>]` は #889 のために予約)。**今の作業スペースと同じなら改訂**: `openClassTabs` は同じファイル名のタブを作り直さず (書いた中身と記録はそのまま)、`ClassProblemStore` の問題文と入出力例だけ差し替え、タブの無い問題だけタブを作る (作ったタブの先頭、無ければ今のタブの問題文を出す)。**違えば `moveToClassWorkspace`**: 移り先の名前空間に `ClassPolicyStore.save(policy, ns)` と `PendingClassPackageStore.put(ns, pkg)` (sessionStorage) を書き、`flushToIndexedDB` を 1 回流してから `skipUnloadConfirm` を立てて遷移する (表示言語の切替と同じく、確認を出さず beforeunload が sessionStorage へ同期保存する = #445)。移り先は起動の最後 (EventRecorder の後・`ready` の前) に `openPendingClassPackage` が配布物を **読んで消してから** 開く (消すので、リロードで二重にタブができない。sessionStorage はブラウザのタブごとなので別のタブには渡らない)。**旧来の名前空間 (`''`・`-class`・`-assignment`・`-exam`) は移さず、コピーせず、消さない** (チェーンと署名がセッション ID に結びついているので、コピーは記録を壊す)。`SingleInstanceGuard` の名前は `instanceGuardNamespace()` (旧来はモード名のまま、作業スペースは `w:<名前>`)。classId が `.` / `..` の配布物はパスに置けない (ブラウザが畳む) ので `isRoutableClassId` で断る。**新しく作業スペースへの入口を足すときも `runClassLoad` を通す** (直接 `openClassTabs` を呼ぶと、今のページの保存領域に別の配布物のタブが混ざる)。回帰は `core/__tests__/mode.workspace.test.ts`・`core/__tests__/storageKeys.test.ts`・`services/__tests__/PendingClassPackageStore.test.ts` と e2e の `scenarios/workspace.spec.ts`
- **入場時の初期状態 (ADR-0015)**: 練習 (casual) は**ウェルカム画面を出さず既定タブ `Untitled-1` を 1 つ自動生成**して即編集 (`main.ts` の entry で `mode==='casual' && !hasAnyTabs` のとき `createTab`)。練習にも「問題を読み込む」は出るが、問題パネル・規約モーダルは出さない (#646。読み込むと作業スペースへ移る)。授業/課題 (旧来の入口と、配布物を受け取っていない作業スペース) はウェルカム + 「問題を読み込む」。作業スペースで配布物を開くと `openClassPackage` が `hideWelcomeScreen` + `openClassTabs` + キャプチャ再有効化/LogViewer 初期化を行う。exam だけ `ExamStartGate` で封印ゲート (下記)。
