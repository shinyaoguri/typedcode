エディタと検証ページに Content Security Policy (CSP) を入れ、ページが読み込み・通信できる先を、アプリ自身が使う配信元 (Turnstile・C コンパイラ・Python のランタイムと PyPI・アイコンのフォントなど) に絞りました。普段の編集・実行・書き出し・検証は変わりません。その代わり、HTML プレビューで外部のサイトから画像・スクリプト・スタイルシート・フォントを読み込むことと、プレビューの中のスクリプトから外部へ通信することができなくなりました。

**移行**: HTML プレビューで外部の画像やライブラリを使っている課題・教材は、CSS と JavaScript を同じセッションの CSS / JS のタブに書き (HTML から `Untitled-2.css` のように参照できます)、画像は `data:` の URL で埋め込んでください。
