C のコンパイルの設定を、授業向けに `-std=c17 -Wall -Wextra -Wpedantic -Werror=implicit-function-declaration -O0` に固定しました (学生は変えられません)。これまでは規格の指定も警告の指定も無く、最適化 (`-O2`) を掛けていました。利用者から見える変化は次のとおりです。

- 未使用の変数・未使用の引数・printf の書式の不一致などの警告が、ターミナルとその行に出るようになります。警告があっても実行は止まりません
- `int main()` のように引数リストに `void` を書かない関数の宣言は、`-Wstrict-prototypes` の警告になります (`int main(void)` と書けば出ません)
- 宣言の無い関数の呼び出し (ヘッダの書き忘れなど) はエラーになり、実行されません
- 最適化を掛けないので、計算の重いプログラムはこれまでより遅く動きます
- 規格は C17 の厳密モード (GNU 拡張のモードではない) になったので、`<math.h>` の `M_PI` や `<time.h>` の `nanosleep` のような POSIX の拡張は、そのままでは宣言されなくなりました (使うとエラーになります)

C++ の設定は変わりません。

**移行**: `M_PI`・`nanosleep` などの POSIX の拡張を使うコードは、最初の `#include` より前に `#define _XOPEN_SOURCE 700` を書いてください (`M_PI` は、値を自分で定義してもかまいません。例: `#define PI 3.14159265358979323846`)。配布している教材やテンプレートのコードも同じです。
