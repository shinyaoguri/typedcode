C / C++ の実行で、ターミナルの入力がローカルの端末と同じように読めるようになりました。Enter は改行 (LF) として届き、打った文字は画面に表示され、バックスペース (日本語を含む) で直した行を `fgets` や `scanf` が読みます。空の行で Ctrl+D を押すか、ターミナルの「入力終了」ボタンを押すと入力の終わり (EOF) を送れます (書きかけの行で Ctrl+D を押したときは、その行を確定するだけです)。Ctrl+C は、ターミナルの文字を選んでいればコピー、選んでいなければ実行の停止になります。Python の入力でも、空の行の Ctrl+D・「入力終了」で EOF を、Ctrl+C で停止を送れます。
