C / C++ の実行で、`#include <stdio.h>` (C++ は `<cstdio>`) を書かずに `printf` などを使うコードが、ネイティブの Clang と同じようにコンパイルエラーになるようになりました。これまではエディタが利用者のコードの前に `stdio.h` を自動で読み込んでいたため、include の書き忘れが見つからずに動いていました。エラーは書き忘れた行に表示され、`#include <stdio.h>` を書けばこれまでどおり実行できます。改行の無い案内文 (`printf("名前: ")`) が入力を待つ前に表示される動き (stdout をバッファしない) は変わりません。プログラムの中で、自分でバッファを渡して `setvbuf` を呼べば、その設定が使われます。

**移行**: C のコードで `printf`・`scanf`・`FILE` などを使っていて、先頭に `#include <stdio.h>` を書いていない場合は、書き足してください (C++ は `#include <cstdio>`)。配布している教材やテンプレートのコードも同じです。
