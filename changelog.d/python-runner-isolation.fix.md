Python のコードを、エディタの記録 (証明の保存領域) から切り離した専用の実行環境で動かすようにしました。実行したコードからは、記録の読み書き・エディタの画面・ブラウザの保存領域に届きません。あわせて、実行したコードからのインターネットへの通信は、Python の実行環境の取得元と、`import` したパッケージを入れるための PyPI だけに限られます (それ以外の URL への `fetch` などは失敗します)。出力が多すぎる場合 (合計 100 万文字を超える場合) は、JavaScript と同じく打ち切って実行を止めます。cross-origin isolation が使えないブラウザでは、Python は実行されずにエラーで終わります。
